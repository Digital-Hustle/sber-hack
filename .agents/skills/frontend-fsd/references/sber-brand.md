# Фирменный стиль Сбера для «Проходной»

Хакатон проводит Сбер, кейс подаём как продукт для экосистемы СберБизнеса. Интерфейс должен выглядеть «как сделал Сбер»: зелёный акцент, много воздуха, крупная типографика SB Sans, мягкие скругления, спокойные поверхности и один яркий градиент там, где нужен вау-эффект.

Готовая тема лежит в `../assets/theme.css`. Копируй её целиком, ничего не придумывай.

## Откуда значения
| Что | Источник | Статус |
|---|---|---|
| «Зелёный СБЕР» `#21A038` (RGB 33/160/56), белый, мастер-градиент | брендбук Сбера 2020 (`Sber Brandbook Rus`, публичная копия) | официально |
| Небесный `#00ADEE`, Синий `#0087CD`, Арктический `#42E3B4`, Весенний `#A0E720`, Солнечный `#FAED00` | гайдлайн СберКорус (дочка Сбера, тот же мастер-бренд) | официально |
| Шкалы `green/gray/red/orange/blue/arctic` 50…1000, семантика text/surface/background | Plasma — открытая дизайн-система Сбера (`salute-developers/plasma`, MIT), тема `sberonline` | открытый код |
| SB Sans Text / SB Sans Display | супергарнитура Сбера (ParaType), CDN `cdn-app.sberdevices.ru` (через него шрифт подключает Plasma) | грузим с CDN, в git не кладём |
| Цифровой брендбук | `brand.sber.ru` | **только по входу**. Если организаторы дадут доступ, сверяем значения и правим тему |

## Цвета: как применять
- **Акцент один — зелёный.** Кнопки и ссылки в светлой теме — `primary` = `#0D8523` (green.700), белый текст 4.78:1, проходит AA. Фирменный `#21A038` с белым текстом даёт только 3.41:1, поэтому его берём для крупных плоскостей, иконок, заголовков от 24 px и «заливки» результата на киоске (`brand`).
- **В тёмной теме** `primary` = `#24B23E` с чёрным текстом (7.16:1).
- **Мастер-градиент** (жёлтый → салатовый → зелёный → бирюзовый → голубой → синий) — это подпись бренда. Используем дозированно: бордер-бим активной карточки, фон логин-экрана, кольцо обратного отсчёта QR, прогресс онбординга. Не используем для заливки текста длиннее двух слов и фона таблиц.
- **Семантика:** успех — зелёный, ошибка — `red.700` `#E31227`, предупреждение — `orange.700` `#D14D00`, инфо — `blue.700` `#0C72B6`. Нейтральные — серые Plasma, а не `slate`/`zinc` из Tailwind.
- **Решение на киоске** красим по `code` из ответа access: `--decision-allow / deny / manual / error`. Цвет выбирает таблица `reasonView`, а не логика клиента (rules.md §1.1).
- В `className` только токены (`bg-primary`, `text-muted-foreground`, `bg-brand-gradient`). Hex в JSX запрещён.

## Типографика
- **SB Sans Text** (300/400/500/600) — весь интерфейс. **SB Sans Display** — заголовки H1–H3, большие цифры на дашборде, экран результата на киоске.
- Шкала (rem): 0.75 / 0.875 / 1 / 1.125 / 1.25 / 1.5 / 2 / 2.5 / 3.5 / 5. Киоск — минимум 1.5rem для текста и 5rem для вердикта. Телефон рабочего — минимум 1rem.
- Межстрочный интервал: 1.2 для Display, 1.45 для Text. Трекинг у Display −0.02em.
- Цифры всегда табличные (`tnum` уже включён в теме): время, счётчики, табель не «прыгают».
- Фолбэк: `system-ui`. Киоск и PWA кэшируют CDN-шрифты через `vite-plugin-pwa` (`runtimeCaching`, `CacheFirst`, 30 дней), чтобы работать без сети.

## Форма и глубина
- Скругления: 8 (чипы) / 10 (инпуты) / 12 (кнопки) / 20 (карточки) / 28 (модалки, bottom sheet). Кнопки не делаем таблетками, кроме FAB и сегментов.
- Тени мягкие и низкие (`shadow-card`), всплывающие слои — `shadow-pop`. Без жёстких бордеров у карточек: фон `card` на `background` + тень.
- Плотность: админка — 8-pt сетка, строка таблицы 44 px. Киоск — тач-цели от 64 px. Телефон — от 48 px.
- Иконки: `lucide-react` (stroke 1.75). Анимированные — `@lucide-animated` (на motion). Свои иконки не рисуем.

## Логотип и знаки
- Знак Сбера и надпись «СберБизнес» — товарные знаки. **Не скачиваем их из интернета и не кладём в git без разрешения.** Агент **запрашивает у человека** официальный SVG от организаторов (медиакит) и кладёт его в `frontend/public/brand/` только с явным «да».
- У продукта «Проходная» свой знак. Простой: турникет или галочка в незамкнутом круге, в мастер-градиенте. Генерируем по запросу (см. ниже) или собираем из lucide.
- Охранное поле вокруг знака — не меньше высоты буквы «С». Не искажаем, не перекрашиваем знак Сбера, не кладём его на пёстрый фон.

## Фотографии и иллюстрации
- **Только реальные или сгенерированные, и всегда по запросу к человеку.** Перед версткой экрана, где нужна картинка (логин, пустые состояния, онбординг рабочего, слайды), агент пишет человеку: «Нужны N изображений: <что, формат, размер>. Пришлёте реальные или сгенерировать?» Стоковые фото с людьми без прав не берём.
- Реальные фото рабочих и лиц — это ПДн. Они живут только в БД (зашифрованы, ADR-009) и в демо-данных, которые вносит человек через интерфейс. **Никогда не в git и не в `public/`.**
- Генерация — нейтральные сцены: стройплощадка на рассвете, каска и QR, турникет. Без узнаваемых лиц. Сохраняем в `frontend/public/img/` в webp ≤ 200 КБ с `width/height` и `loading="lazy"`.
- Стиль: фото с лёгким зелёным тонированием (overlay `bg-brand/10`) или 3D-иллюстрации в стиле Сбера (мягкий пластик, зелёно-бирюзовые тона).

## Тон текстов
На «вы», коротко, по-человечески, без канцелярита. Ошибка = что случилось + что делать: «QR устарел. Обновите код в телефоне». Цифры — с единицами и временем: «На объекте 47 человек · обновлено 14:02».
