# RULES — правила для AI-агентов во frontend

Сверху действуют `../../rules.md` (красные линии) и скилл `frontend-fsd`. Здесь — конкретно для нашего фронта. Нарушение пунктов с ⛔ = PR не принимается.

## Делай
- Работай в своей зоне и своём слайсе (владельцы — `../AGENTS.md`). `shared`/`entities`/`app` — PR с ревью F2.
- Сначала найди существующее: `grep -r` по `shared/ui`, `entities`, `features` — не создавай второй Button/Select/формат даты.
- Данные: `entity/api/<x>Api.ts` → `queries.ts` (фабрика ключей) → компонент. Запись — `features/<verb-noun>/api/mutations.ts` + `invalidateQueries`.
- Каждый экран: skeleton / empty / error с «Повторить» / data / offline-баннер.
- Тексты стадий, отказов и причин — из ответа бэка (`detail`/`hint`) или `t("stages.<stage>")`/`t("reasons.<code>")` по таблицам `../../docs/API.md`; ключи сразу в `public/locales/ru`.
- Стили — только классы токенов из `docs/DESIGN.md`. Нужного токена нет → добавь его в `shared/config/tokens.ts`, `npm run gen:tokens`, опиши роль токена (PR с ревью F2).
- Анимации UI — `motion/react` и пресеты `@/shared/config/motion`.
- Перед PR: `documents/scripts/ci-local.sh quick`, руками проверь экран в браузере (кабинет — 390×844, оператор — 1440×900), опиши шаги в PR.

## Избегай
- ⛔ Решать на клиенте тип документа, пригодность файла или полноту комплекта (Д1, СН) — клиентская проверка размера/формата только подсказывает, отказ всегда от intake.
- ⛔ Передавать имя файла/пункт как «тип»: `slotType` уходит только как пункт загрузки.
- ⛔ Токенов и ключа заявки в localStorage; ключа в query-строке URL и логах.
- ⛔ Моковых данных и MSW вне `src/mocks` и `import.meta.env.DEV`; примерных заявок/метрик на пустой БД.
- ⛔ hex/rgb в коде, `p-[13px]`/`text-[#fff]`/`w-[420px]`, отступов вне сетки, `duration: 0.3`/`ease: [...]` литералами, `style={{ padding: 12 }}` — правила `fsd-check`.
- ⛔ Дублирующие движки анимаций (`framer-motion`, `react-spring`, `anime.js`); CSS `@keyframes`/`animate-*` вне `shared/ui`.
- ⛔ Показывать оператору ПДн из кэша после выхода; рендерить файлы через публичные URL — только blob из `/files/{id}/content` с токеном, `URL.revokeObjectURL` при уходе.
- Ручного `fetch`/`axios` в компонентах; копирования серверных данных в zustand; `useEffect` для загрузки данных.
- Глубоких импортов в чужой слайс, импортов вверх по слоям, `@x`-нотации.
- Нативных `<select>`, `<input type=date>`, браузерных скроллбаров и `alert/confirm` — только кастомные контролы (`frontend-fsd/references/custom-controls.md`).

## Библиотеки
Разрешены: из `docs/ARCHITECTURE.md §Стек` + компоненты из реестров `components.json` через `npx shadcn add`, с адаптацией под токены. Новая npm-зависимость → проверь лицензию (MIT/Apache/BSD/ISC; GPL/AGPL нельзя), строка в `../../docs/DECISIONS.md`, ревью F2 (`package.json` — его). Запрещены: `react-pdf` с GPL-зависимостями, PDF.js-форки без лицензии, `tesseract.js` (распознавание — только на сервере).

## Обработка ошибок
- Ответ ошибки — `application/problem+json` (`shared/api/problem.ts` → `{code, detail, hint, errors[]}`); показываем `detail`/`hint` с бэка или `t("errors.<code>")`, никогда сырой stack/JSON.
- Отказ загрузки — это не toast, а состояние пункта (`UploadSlot` с текстом и кнопкой «Загрузить другой файл»).
- 401 оператора → refresh в интерсепторе `$api`, повтор один раз, затем на вход. Ключ заявки неверный → экран «Ссылка недействительна» + ввод кода возобновления. 403 → `ForbiddenPage`. 404 → empty. 5xx/сеть → error с «Повторить».
- Загрузка: прогресс, отмена, повтор при обрыве сети; повторное нажатие заблокировано; `Idempotency-Key` для создания заявки.
- Глобальный `ErrorBoundary` на зону: «Что-то пошло не так» + «Перезагрузить», ошибка в консоль с `traceId`.

## Ограничения
- Камера — только HTTPS; проверяем на iOS Safari и Android Chrome. Снимок сжимаем до ≤ 4 МП/≤ `UPLOAD_MAX_MB` перед отправкой (без потери читаемости).
- Кабинет — телефон-first, тач-цели ≥ `h-control-md`; оператор — десктоп, `h-control-sm`/`md`.
- Бандл зоны грузится лениво; `pdfjs-dist` — только в зоне оператора.
- Продуктовый код — только в день хакатона (п. 7.3 положения); до этого — только документы и скиллы.
