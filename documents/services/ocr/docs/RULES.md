# RULES — ocr (для AI-агентов)

Сверху действуют `../../../rules.md` (красные линии), `../../../docs/WORKFLOW.md` и скилл `backend-spring`. ⛔ — PR не принимается.

## Делай
- Работай только в своём сервисе; другие сервисы зовут тебя по HTTP с service-account JWT (`aud=ocr`), сам ты никого не зовёшь.
- Сначала контракт: OpenAPI FastAPI (`/openapi.json`) + строка в `../../../docs/API.md`, отдельным маленьким PR.
- Типы везде (`mypy --strict`), pydantic-модели на вход/выход, ruff + format.
- Тест вместе с кодом (pytest); фикстуры — синтетические документы из `../../../eval/synthetic/`, не реальные ПДн.
- Перед PR: `documents/scripts/ci-local.sh quick`, перед ready — `full`; статус в `docs/TASKS.md`, состояние и журнал в `docs/MEMORY.md`.
- Метрики качества — числа, пороги решений — в docproc (ocr только измеряет).
- Новая предобработка — тест на синтетической картинке и прогон eval у B2 (точность может упасть).

## Избегай
- ⛔ Моков, заглушек, «временных» ответов и захардкоженных данных в боевом пути (rules.md §1) — честная ошибка.
- ⛔ Хранения файлов/результатов в памяти между запросами или на диске — сервис stateless, данные живут в PostgreSQL владельцев.
- ⛔ Отключения тестов, ruff, mypy, проверок CI «чтобы прошло».
- Логирования содержимого документов, распознанного текста и ПДн — только длины, метрики и `documentId`.
- ⛔ PyMuPDF (fitz), pdf2image/poppler, ghostscript, Wand/ImageMagick-биндинги в образе (GPL/AGPL, ADR в DECISIONS).
- ⛔ Определять тип документа или извлекать поля в ocr — это зона модели в docproc.
- ⛔ EasyOCR/PaddleOCR без ADR (размер образа, лицензии весов).

## Библиотеки
Разрешены: из §Стек ARCHITECTURE. Запрещены: PyMuPDF, poppler-обёртки, ghostscript. Новая зависимость — только с разрешённой лицензией (без GPL/AGPL, п. 5.8.4), строка в `../../../docs/DECISIONS.md`, версия в `gradle/libs.versions.toml` (B1) или `pyproject.toml`.

## Обработка ошибок
- Ошибки — problem+json (`code`, `detail`): `FILE_CORRUPTED` (422), `TOO_MANY_PAGES` (422), `UNAUTHORIZED` (401); исключение распознавания одной страницы → страница с `error`, остальные отдаются.
- Тайм-аут страницы (`OCR_PAGE_TIMEOUT`) → страница с `error=TIMEOUT`, а не 500.

## Ограничения
CPU-only. Страница ≤ 5 с, документ ≤ 10 страниц ≤ 30 с; `workers = CPU/2`. Порт не публикуется наружу.
