# MEMORY — ocr

Память модуля между сессиями и агентами. §1 — перезаписываемое текущее состояние (≤ 10 строк). §2 — карта, обновлять при новых пакетах/файлах. §3–4 — добавлять строки, неактуальное ~~зачёркивать~~. §5 — **только дописывать в конец** (`merge=union`). Решения для всей системы — ADR в `../../../docs/DECISIONS.md`.

## 1. Текущее состояние
- Реализовано: /v1/extract (текстовый слой pdfplumber или рендер pypdfium2 → deskew+CLAHE → Tesseract rus+eng, подбор ориентации 0/90/180/270, EXIF), метрики качества (blur/brightness/glare/cutOff/dpi), MRZ TD1/TD2/TD3 с контрольными цифрами, /v1/render (PNG в тех же координатах, что bbox), JWT aud=ocr + роль SERVICE_DOCPROC, /metrics.
- bbox: [x0,y0,x1,y1] в пикселях страницы width×height (рендер OCR_DPI, длинная сторона ≤ OCR_MAX_SIDE_PX).
