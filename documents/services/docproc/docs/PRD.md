# PRD — docproc

Продукт целиком — `../../../docs/PRD.md`, требования с ID — `../../../docs/REQUIREMENTS.md`. Здесь — только этот модуль.

## Обзор
Фоновый конвейер: из `DocumentReceived` создаётся задание; воркеры по стадиям получают текст (ocr), определяют вид документа по содержимому, извлекают поля по JSON Schema вида, нормализуют и проверяют их, считают уверенность и публикуют результат. Переживает рестарт и недоступность модели (Д7, С11–С12).

## Проблемы
- Разбор должен делать модель по содержимому файла (Д5), а не имя файла/пункт/шаблон (СН).
- Модель медленная и иногда падает или отвечает не по схеме — приём не должен ждать, задания не должны теряться.
- Фото с телефона бывают нечитаемыми — нужно честно сказать «не прочитать» с причиной, а не выдумывать поля.
- Нужна измеримая точность на открытом наборе по всем 8 видам (Д11).

## Цели
1. Точность типа и полей на открытом наборе — отчёт `eval/` в каждом PR, меняющем промпты/предобработку.
2. Рестарт посреди разбора — продолжение с сохранённой стадии, без дублей (тест).
3. Модель недоступна → `WAITING_MODEL`, автоповтор, без траты попыток.
4. Каждое поле: значение, сырой текст, страница, bbox, уверенность, проверки.

## Пользователи
- intake — получает стадии и итог (SSE соискателю).
- review — получает результат для оператора, запускает переразбор.
- B2/судьи — метрики стадий, журнал вызовов модели.

## Ключевые функции
- Очередь `jobs` (SKIP LOCKED + lease 2 мин, экспоненциальная пауза), `stage_events`, `stage_outputs`.
- Стадии: EXTRACTING_TEXT (ocr) → CLASSIFYING → EXTRACTING_FIELDS → VALIDATING → PARSED | NEEDS_REVIEW | UNREADABLE.
- Классификатор: `LlmGateway.structured` по тексту + признакам ocr (MRZ, ключевые слова как подсказки модели, не правило); `TYPE_UNKNOWN` при низкой уверенности.
- Извлечение по схеме `doc_types.schema`; vision-путь при слабом OCR.
- Нормализация и проверки: даты, MRZ (контрольные цифры ICAO 9303), СНИЛС, ИНН, серия/номер, срок действия.
- Уверенность поля (ADR-011), порог «перепроверить».
- Журнал `llm_calls`, `GET /model/status`, «разобрать заново».
