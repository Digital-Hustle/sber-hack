## 4. Риски
| Риск | Что делаем |
|---|---|
| Локальная модель медленная на CPU (минуты на документ) | qwen3:4b как запасная, лимит текста, кэш стадий, параллельность воркеров; на защите — облако + показ локального режима |
| Tesseract плохо читает фото с телефона | предобработка, vision-путь, PaddleOCR как второй движок (ADR) |
| Набор 8 видов другой | реестр `doc_types` и `doc_requirements` — данные, схемы правятся миграцией |
| Слабый интернет на площадке | образы, модели, tessdata скачаны заранее |
| Кейс достанется другой | общий каркас и процесс те же, что у «Проходной» и «Субсидий» |
