## A. Приём и проверка входящего (12 баллов; Д2)
| ID | Требование | P | Критерий |

## I. Чек-лист «не снимут» (прогоняем перед защитой)
- [ ] `curl` на эндпоинты оператора и `/files/{id}/content` без токена → 401; с ключом чужой заявки → 404
- [ ] Загрузка файла отвечает мгновенно; стадии видны по очереди; в логах docproc — вызов модели на каждый документ
- [ ] `docker compose restart docproc` во время разбора → задание доделано, ничего не потерялось; `restart postgres` → всё на месте
- [ ] `docker compose stop ollama` → документы в `WAITING_MODEL`, не «готово»; `start` → догнали сами
- [ ] Переименовать файл (`passport.jpg` → `x.pdf`, расширение не то) → тип определён так же; пустой/битый файл → понятный отказ
- [ ] Свой документ, которого нет в открытом наборе (паспорт члена команды, синтетика) → поля извлечены
- [ ] Чистая БД → очередь пустая, метрики нули
- [ ] Все 8 видов на открытом наборе → тип определён (Д11), результат прогона `eval/` приложен
- [ ] `LLM_PROVIDER=ollama`, интернет выключен → разбор работает
- [ ] `gitleaks detect` по всей истории — чисто; в git нет сканов
- [ ] Каждый рассказывает свой модуль за 60 с
