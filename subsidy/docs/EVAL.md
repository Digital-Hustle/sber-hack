# Оценка качества — честно и без подгонки

Определение вида (25 баллов) и извлечение полей (часть 20) судьи проверяют **на своих пакетах**, которых у нас нет. Единственная выигрышная стратегия — обобщение, а не запоминание открытого набора (rules.md §1.4).

## Наборы
| Набор | Где лежит | Для чего |
|---|---|---|
| Открытый (от организаторов) | **вне git**: `~/datasets/subsidy-open/` у B2 и на сервере, путь в `EVAL_OPEN_DIR` | замер, разбор ошибок по категориям |
| Синтетический | `eval/synthetic/` в git (сгенерированные документы вымышленных организаций с корректными контрольными суммами) | CI, регресс, few-shot |
| Свой «закрытый» | вне git: документы с открытых источников и собственные образцы, переснятые/склеенные/повёрнутые | имитация чужих пакетов |
| Атакующий | `eval/synthetic/adversarial/` | переименованные файлы, перемешанный порядок, склеенные PDF, инъекции в тексте, посторонние документы |

Разметка: `eval/labels/<set>.jsonl` — `{file, segments: [{fromPage, toPage, type}], fields: {docIndex: {name: value}}, expectedRules: {code: status}}`.

## Метрики (`eval/run.py` → `eval/reports/<date>.md`)
- **Тип**: accuracy и macro-F1 по 8 видам, матрица ошибок, доля `TYPE_UNKNOWN` (честная неуверенность лучше ошибки), точность сегментации (страницы → документ).
- **Поля**: exact match после нормализации, precision / recall по полю, «выдумано» (заполнено, а в документе нет), отдельно деньги (точно до копейки) и реквизиты.
- **Правила**: совпадение статусов правил с разметкой на синтетике (проверяет весь конвейер, включая арифметику).
- **Уверенность**: калибровка (корзины 0.9+ → ≥ 0.9 верных) — для порогов `CLASSIFY_MIN_CONFIDENCE`, `FIELD_REVIEW_THRESHOLD` и бонуса B-08.
- **Время**: p50/p95 на документ по стадиям, провайдер и модель.

## Правила против подгонки
1. Изменение промпта/порогов принимается, только если оно не ухудшает свой «закрытый» и атакующий наборы.
2. Никаких условий по конкретным значениям из открытого набора (ИНН, наименования, имена файлов). `guard.sh` ищет имена тестовых файлов в коде и промптах.
3. Разбор ошибок — по категориям (скан под углом, таблица без линий, УПД vs счёт-фактура, склейка), фиксы — общие.
4. В отчёте честно пишем, где ошибаемся.

## Как запустить
```bash
cd subsidy/eval
uv run python run.py --set synthetic                   # CI
EVAL_OPEN_DIR=~/datasets/subsidy-open uv run python run.py --set open --api https://<host>
```
`run.py` создаёт пакет и грузит файлы через **публичный API** (как специалист), ждёт протокол и сравнивает типы, поля и статусы правил с разметкой — меряем систему целиком.
