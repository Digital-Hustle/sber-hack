# Кейс 9.1.3 Автоматическая проверка пакета документов на получение субсидии

> Статус: подготовка. Ждём полный текст кейса. Каркас переиспользуем из `proxodnaya/`.

## Допуск (зачёт/незачёт)
Д1 стенд по инструкции · Д2 отдельный бэкенд, проверка документов и правил на нём · Д3 фронт рабочего места специалиста · Д4 данные переживают рестарт · Д5 модель реально определяет тип и извлекает поля · Д6 изоляция модели, локальный провайдер + инструкция · Д7 репо, история, без секретов · Д8 документация 5.5, журнал решений, схема · Д9 тип из содержимого, не из имени/порядка · Д10 все 8 видов на открытом наборе · Д11 правила и арифметика на сервере · Д12 каждый объясняет свой код

## Баллы (100)
Определение типа 25 · Комплектность 15 · Извлечение полей и правила 20 · Модель и локальная 15 · Рабочее место специалиста 10 · Инженерная культура 10 · Владение 5

## Бонусы (+10)
сверка ИНН и др. между документами · протокол проверки в файл · история по организации · статистика частых ошибок · истекающие документы · помощник по пакету + аномалии · частичный пакет: чего не хватает · уверенность типа по файлу

## Снятие
тип по имени/порядку/расширению · правила на клиенте · данные в памяти/файле · заготовленные результаты · нет модели или заготовленный ответ · подгонка полей · секреты в репо · не можете объяснить
