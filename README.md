## Для агентов
Начни с [`AGENTS.md`](AGENTS.md). Скиллы — в [`.agents/skills/`](.agents/skills/) (`.claude/skills` — симлинк).

## Общие правила
- Код продукта пишется только на хакатоне (п. 7.3). До старта в репозитории — документация, правила, CI и инструменты.
- Никаких секретов в git. `.env` только локально и на сервере.
- Работа только через PR, мерж — человек-владелец после зелёного CI.
