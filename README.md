## Стенд: на сервере живёт один кейс
На общем сервере (`217.12.40.215`) одновременно развёрнут **только один кейс** — какой выдадут на хакатоне. Перед деплоем
своего кейса агент проверяет, что чужой стенд остановлен (`docker compose ls`), и при необходимости останавливает его
**без удаления томов** (`docker compose -f <кейс>/infra/docker-compose.yml down`, без `-v`). Порты 80/443 держит общий
edge-прокси (`edge/`, TLS и маршрут по хосту `<кейс>.<домен>`), кейс за ним слушает `127.0.0.1:<порт>`. Порядок, порты и DNS —
[`edge/README.md`](edge/README.md). Письма всех кейсов (коды входа, приглашения) уходят через общий почтовый узел —
[`mail/README.md`](mail/README.md).

## Общие правила
- Код продукта пишется только на хакатоне (п. 7.3). До старта в репозитории — документация, правила, CI и инструменты.
- Никаких секретов в git. `.env` только локально и на сервере.
- Работа только через PR, мерж — человек-владелец после зелёного CI (или агент по явному делегированию, запись в `docs/MEMORY.md §3` кейса).
