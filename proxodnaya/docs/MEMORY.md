## 1. Текущее состояние
- Дата: 2026-10-08, до очного этапа (10.10.2026, Ростов). Продуктового кода нет и не будет до старта (п. 7.3) — в репо только документы, скиллы, скрипты, CI.
- Готово: документы кейса и модулей, скиллы агентов, дизайн-токены и генератор темы, процесс работы (WORKFLOW.md), локальный CI.
- Ждём: полный текст кейса (С1–С22, разд. 5.3/5.5) → сверить REQUIREMENTS.md и DEMO.md; логины участников → CODEOWNERS и ROLES.md.
- Перед стартом: репо публичное + branch protection на `main` (B1).
