# Защита: сценарий, матмодель, вопросы

Формат по положению (п. 7.6): презентация + **математическая модель** + демонстрация работоспособности. Судьи проверяют сами, руками, на нашем стенде — готовим им «маршрут судьи».

## Маршрут судьи (держим распечатку на столе)
1. Админка → «Новый сотрудник» → судья вводит своё ФИО → фото с вебкамеры → смена на сейчас → инвайт-QR (Д9).
2. Судья сканирует инвайт своим телефоном (или нашим запасным) → PWA → динамический QR.
3. Киоск → вход → челлендж → ✅. Админка: обстановка обновилась сама (B-02), в журнале запись.
4. Атаки: тот же QR ещё раз → QR_REUSED; QR судьи + лицо другого → FACE_MISMATCH; фото судьи с телефона → LIVENESS_FAILED; скриншот через 30 с → QR_EXPIRED; телефон в авиарежиме всё равно показывает рабочий QR (подпись на устройстве); вход повторно → ALREADY_INSIDE.
5. Выход → интервал закрыт, отработанное время посчитано.
6. `docker compose restart backend` → всё на месте (Д4).
7. Аналитика → фильтры → табель XLSX.
8. Помощник: 2 вопроса + ловушка. Переключение на Ollama, интернет выключен.
9. Репозиторий: история, docs, DECISIONS, `gitleaks` чисто.

## Математическая модель (1 слайд + 1 запасной)
- **Сверка лица**: эмбеддинги e₁, e₂ ∈ ℝ¹²⁸, s = e₁·e₂ / (‖e₁‖‖e₂‖). Проход, если s ≥ τ. Порог τ выбираем по распределениям «свой/чужой», снятым на команде (N пар): график FAR(τ)/FRR(τ), τ ставим так, чтобы FAR ≈ 0 ценой FRR в несколько процентов. Агрегация по k кадрам: медиана sᵢ.
- **Живость**: yaw ≈ f(смещение носа относительно середины глаз, нормированное на межглазное расстояние); челлендж пройден, если Δyaw в нужную сторону > θ и s(кадрᵢ, кадрⱼ) ≥ τ.
- **Пропуск**: окно атаки ≤ TTL = 30 с, токен одноразовый ⇒ повтор невозможен; подбор nonce: 2⁻¹²² за попытку; вместе со сверкой лица: P(проход за другого) ≤ FAR × P(получить живой токен жертвы).
- **Время**: worked = Σ |[entry, exit] ∩ [shift_start − g, shift_end + g]|; late = max(0, first_entry − shift_start − tol); overtime = max(0, last_exit − shift_end − tol).
- **Скопление**: occ(z, t) = Σ входов − Σ выходов; alert, если occ > cap(z) дольше Δt.
- **Честность метрики отказов**: rate = DENY / attempts, разложено на «правомерные» (правила, чужое лицо) и «системные» (качество кадра, ошибки), то есть качество самой системы.

## Структура слайдов (≤ 7)
1. Проблема стройки: «пропуск за друга», бумажный табель
2. Решение и три интерфейса (скрины)
3. Почему не пробить: сервер решает, динамический QR, лицо 1:1, живость (схема)
4. Матмодель
5. Смены, аналитика, помощник без выдумок, локальная модель
6. Инженерия: архитектура, журнал решений, наблюдаемость, лицензии, ПДн
7. Команда и кто за что отвечал
