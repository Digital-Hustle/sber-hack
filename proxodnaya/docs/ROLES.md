## Общие обязанности
- **Капитан (B1)**: оргвопросы с модератором, мерж в `main`, теги `demo-N`, итоговое решение по срезу scope. Нужна доверенность (см. положение).
- **Хранитель документации** — каждый для своего модуля; B1 сводит README и DECISIONS. ADR пишет тот, кто принял решение.
- **Тестировщик-«злоумышленник»** — по очереди: каждые 2 часа один человек 15 минут пытается пройти за другого и ломает систему по чек-листу H из REQUIREMENTS.
- **Презентация** — F2 собирает слайды (из DEMO.md), B2 отвечает за слайд матмодели, B1 — за итоговую репетицию.

## Пары (агенты пишут быстро, интеграция — узкое место)
- B1 ↔ F1/F2: OIDC-клиенты Keycloak, device-auth рабочего, подпись киоска — в первые 45 минут.
- B2 ↔ F1: контракт киоска (`/access/api/v1/kiosk/*`), формат офлайн-QR и коды отказов.
- B1 ↔ B2 ↔ B3: схемы событий `contracts/events/` и внутренние API (`/internal/**`) — в первый час.
- B2 ↔ F1/F2: формат кадров (JPEG base64, 640×480, 3–5 шт.), эндпоинт заведения эталона.
- B3 ↔ F2: аналитические эндпоинты и формат ответа помощника (текст + sources + таблица).

## Роли агентов (у каждого человека 1–2 агента одновременно, в разных worktree)
| Роль | Что делает | Чего не делает |
|---|---|---|
| **Автор** (агент человека-владельца) | одна задача из TASKS: draft PR, коммиты по ходу, ci-local, handoff, MEMORY | не мержит, не трогает чужие модули без согласия, не меняет контракт без PR-контракта |
| **Ревьюер** (новая сессия или агент другого человека) | `gh pr checkout` → ci-local full → чек-лист `pr-workflow.md` → комментарии | не апрувит и не пушит в чужую ветку без просьбы |
| **Исследователь** (отдельная сессия) | разбирается в библиотеке/баге, приносит вывод в MEMORY/PR | не коммитит продуктовый код |
| **Человек-владелец** | ставит задачу, читает handoff, проверяет руками в UI, мержит после зелёного CI | не мержит непроверенное «потому что агент сказал готово» |
Процесс целиком — `WORKFLOW.md`.
