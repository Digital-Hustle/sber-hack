# PRD — shift

Продукт целиком — `../../../docs/PRD.md`, требования с ID — `../../../docs/REQUIREMENTS.md`. Здесь — только этот сервис.

## Обзор
Превращает поток проходов в рабочее время: плановые смены, интервалы присутствия по зонам, отработанные часы, опоздания и переработки, честная аналитика и табель для бухгалтерии. Здесь же правила оповещений и SSE-хаб «обстановка в реальном времени» (бывший notify, ADR-030).

## Проблемы
- Учёт времени на стройке ведут вручную, ночные смены через полночь ломают простые отчёты.
- Человек вышел без отметки — интервал «висит», и цифры молча врут.
- Руководителю нужно видеть, кто на объекте сейчас, без обновления страницы.
- Красивые графики на пустых данных — прямой путь к снятию баллов за честность метрик.

## Цели
1. Интервалы корректны для ночных смен, смены зоны и пропущенного выхода (`IntervalCalculatorTest`).
2. Каждая метрика — SQL по реальным событиям, с подсказкой «как посчитано»; неполные данные — отдельно (FR-32, FR-34).
3. Падение shift не мешает проходам; после подъёма догоняет `access.pass.v1` со своего offset.
4. Табель XLSX за период за один клик (B-06).

## Пользователи
- ADMIN — смены и шаблоны, массовое назначение.
- MANAGER — дашборд, аналитика, отчёты, оповещения.
- Рабочий — свои смены, статус, напоминание о выходе.
- access — `/internal/shift/.../active-shift`; assistant — `/internal/shift/**` (read-only).

## Ключевые функции
- Смены и шаблоны (день/ночь), массовое назначение бригаде.
- Консьюмер `access.pass.v1` → интервалы: вход открывает, внутренняя проходная — `ZONE_CHANGE`, выход — `EXIT`; автозакрытие `AUTO_SHIFT_END` + `UNCONFIRMED_EXIT`.
- Аналитика: summary, hours, late-overtime, refusals, load-by-hour, occupancy — с общими фильтрами.
- Табель XLSX (Apache POI), отчёт по человеку.
- SSE `/stream/situation` и `/stream/worker` по одноразовому ticket; heartbeat телефона; правила оповещений B-01, B-04, B-05.
- `/internal/shift/workers/{id}/active-shift` для access (быстрый, индексированный).
