# MEMORY — frontend

Память модуля между сессиями и агентами (по мотивам Cline Memory Bank). Правила:
- §1 — **перезаписываемое** текущее состояние (≤ 10 строк, правит владелец/агент задачи в конце сессии).
- §2 — карта: обновляй, когда добавил слайс/важный файл.
- §3–4 — решения и баги: добавляй строку, неактуальное помечай ~~зачёркнутым~~, не удаляй.
- §5 — журнал: **только дописывать в конец** (`.gitattributes: merge=union`, параллельные ветки не конфликтуют).
Архитектурное решение для всей системы — ADR в `../../docs/DECISIONS.md`, здесь только ссылка.

## 1. Текущее состояние
- Код — порт `proxodnaya-sandbox` (FE-01): одно SPA, зоны `/admin`, `/kiosk`, `/worker`, BrowserRouter, сборка `Dockerfile` (caddy, SPA fallback).
- Данные — `src/shared/api/remote/`: `http.ts` (fetch через gateway `/<svc>/api/v1`, problem+json, renew на 401), `auth.ts` (staff в памяти + refresh, device-токен ES256, подпись киоска), `store.ts` (кэш Db по ролям, SSE `/shift/stream/situation`, опрос), `server.ts` (все `api.*`), `devices.ts` (киоск, телефон).
- Ждут бэкенд по `../../docs/BACKEND-CONTRACT.md`: киоски ACC-12, офлайн-снимок ACC-15, `/kiosk/identify`, `/worker/me*`, review лица, refresh-cookie PPL-14. Пока их нет — соответствующие экраны показывают ошибку сервера.
- Без PPL-14 перезагрузка кабинета = повторный вход (токены только в памяти).

## 3. Решения модуля
| Дата | Решение | Почему | Ссылка |
|---|---|---|---|
| 2026-10 | `primary` = кнопка Nova `#148F2B`, hover — `primary-hover` | как на sberbank.ru; контраст 4.2:1 → текст кнопок semibold 16+, мелкий зелёный текст — `accent-foreground` | ADR-033 |
| 2026-10 | Киоск всегда в тёмной теме | вердикт контрастнее, меньше бликов | DESIGN.md §6 |
| 2026-10-08 | От Сбера — только зелёный и SB Sans, радиусы и прочее — свои современные; WebGL/GSAP разрешены | цель — сильный визуал, полный брендбук закрыт | ADR-036 |
| 2026-10 | Дефолтная палитра/размеры/анимации Tailwind выключены в теме | физически нельзя взять `red-500`/`animate-spin` мимо токенов | ADR-033 |
| 2026-10 | Порт песочницы: кэш `Db` над API (`useDb`) вместо TanStack Query | страницы песочницы уже читают синхронный `Db`; переписывать 40 страниц на хуки запросов — дни работы. Кэш обновляется SSE и опросом, мутации делают `reload(part)` | FE-01 |
| 2026-10 | QR пропуска — формат сервера `v1.<workerId>.<deviceId>.<window>.<sig>`, без ключа в QR | ключ телефона сервер знает с активации, офлайн-терминал берёт его из снимка; неизвестный телефон — только DENY | FE-01 |
| 2026-10 | Нет заводского кода охранника | ручной пропуск без связи — только после того, как код задан в кабинете; сервисный заводской код остаётся для первого запуска киоска | FE-01 |
